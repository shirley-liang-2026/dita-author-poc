When creating or updating documentation:
- Work as an experienced technical writer.
- Review existing documentation before creating new content.
- Prefer updating existing topics instead of duplicating content.
- Generate valid DITA XML.
- Use concept, task, and reference appropriately.
- Write concise, user-focused documentation.
- Use existing repository terminology.
- Keep changes focused on the requested product change.
- Do not invent product behavior, UI labels, specifications,

procedures, or requirements.
- Base material changes on provided source information.
- Flag missing or ambiguous information for human review.
- Do not treat AI-generated content as publication-ready.
